# SoSe26_Case_Study_Group_44

Case study of group 44 for the course "Introduction to Engineering Data Analytics"

Submission Requirements:
Final Project Instructions and Submission Requirements

Group Work

The final project is assessed as a group project. Good communication and a clear division of tasks will make
the work easier, make it as soon as possible. If a group member does not participate, first try to resolve the
issue within the group. If no solution is found, inform the teaching team as early as possible, preferably within
the first two weeks. This helps us address the issue before the group is negatively affected.

Many technical questions can be solved through documentation, forums, and other online resources. The
final  project  consists  of  general  tasks,  case  study:  Data  analysis  and  web  application.  Download  your
assigned case study from ISIS. The required Data folder is available on tubCloud through the link provided
on ISIS.

Folder Structure

1.  Create  a  project  folder  named:  SoSe26_Case_Study_Group_<GroupNumber>.  Submit  two

Jupyter Notebooks and their HTML exports and Web application as python file:

o  General tasks:

SoSe26_General_Tasks_Group_<GroupNumber>.ipynb

o  Case study:

SoSe26_Case_Study_Group_<GroupNumber>.ipynb. In the file Table of Contents should
include things like: Importing the data, Data preparation, Creation of the final dataset,
Evaluation and Result.

o  Web Application (Dash and/or Streamlit):

SoSe26_Case_Study_App_Group_<GroupNumber>.py

2.  Sub-folders to include in the submission folder:

o  Additional_files: Screenshots of app and other files do not fit other cases
o  Data: original data in its folder, and final data:

SoSe26_Case_Study_finalData_Group_<GroupNumber>.csv
o  www: static app files such as images, CSS, JavaScript, and fonts.

Code and Documentation Requirements

- Your  documentation must  include  all  code used during  the  analysis.  Each  big  step  should  be explained
briefly and clearly. Code that does not run or does not produce the required results will not be evaluated and
will receive zero points for the affected section.

- Please do not let trash/dead code and comments. It is an examination document.

- The submitted notebooks must meet the following requirements:

•  For submission, you must compress the files into a .zip

•  Run all cells before saving so that the latest outputs are visible.

•  Ensure that all code works on an updated Anaconda installation.

•  Always add screenshots of WebApp in case it does not work. Submit different screenshots where

one can see the functionalities of the App.

•  Clean the data according to the methods and rules taught in the course.

•  Comment on the code clearly enough for non-specialists to understand the main steps in terms of

business, statistics and data.

•  Suppress unnecessary warnings and system messages.

•  Make sure the complete analysis can be reproduced from the original data.

•  Do not modify the original data files.

•  Do not submit the original dataset. Submit all other files and keep the original data folder empty.

We will place the original data there and run your code.

•  Submit only the final dataset from your analysis required by your application.

•  Store file paths and data-loading steps so that the analysis works when the original data is placed in

the documented folder.
