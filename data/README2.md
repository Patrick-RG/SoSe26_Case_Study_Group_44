# Data Directory

This folder is intended to store the local datasets required for this project. 

Due to size limits, the data files are not tracked by Git. You can download the full dataset as a ZIP file from the following link:
[tubcloud Data Share](https://tubcloud.tu-berlin.de/public.php/dav/files/q7DHz7j9wPiaeGc/?accept=zip)

**Instructions:**
1. Download the ZIP file using the link above.
2. Extract the contents directly into this `data/` folder.
